# Backup & Portability

Since all configurations are stored locally in your browser, you might want to back them up or move them to another machine.

## Exporting Configuration

1. Open the **Layout Manager**.
2. Go to the **Settings** tab.
3. Click **Export Config**.
4. A `.json` file containing all your views, layouts, and custom logic will be downloaded to your computer.

## Importing Configuration

1. Open the **Layout Manager** on the new device/browser.
2. Go to the **Settings** tab.
3. Click **Import Config**.
4. Select the `.json` file you previously exported.
5. Your dashboard will refresh and load all imported views.

> [!WARNING]
> Importing a configuration will **overwrite** your current local views. Make sure to export your current state first if you want to keep it.
